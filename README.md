# Bairro a Bairro

Jogo de tabuleiro estilo Monopoly com bairros e cultura de Luanda, Angola.

**Jogar:** [https://bayyurt.github.io/bairro-a-bairro/](https://bayyurt.github.io/bairro-a-bairro/)

Hot-seat 2 jogadores · dados · compra/renda · Sorte/Azar · 30 turnos ou falência.

Não afiliado à Hasbro. Propriedades e nomes ficcionais/inspirados.
